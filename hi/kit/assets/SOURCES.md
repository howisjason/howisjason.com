# Where every picture in the Sky kit comes from

Each file lives here, so no page ever loads a picture from someone else's server. One line per
file. A new picture gets its line in the same commit.

- `sky.jpg`: white clouds under a blue sky, softened for a page background: blurred, a touch
  lighter and less saturated, 1280 x 853 (about 20KB; blurred, it looks the same stretched to a
  big screen). Copied on 11 Nov 2026 from howisjason.com's `img/sky.jpg`, where it was made.
  Unsplash, by engin akyurt,
  https://unsplash.com/photos/white-clouds-under-blue-sky-during-daytime-gJILnne_HFg .
  Unsplash License (free to use, credit appreciated, not required).

## Icons

Icons are not pictures in this folder. They come from **Lucide** (https://lucide.dev): pasted into a
page as SVG, or made into a project's own `icons.css` by `tools/make-icons.mjs` (the demo's is
`demo/icons.css`). Both are Lucide's own drawings, not redrawn, under the ISC licence:
Copyright (c) 2026 Lucide Icons and Contributors. The ISC licence lets anyone use, copy and change
them, free, as long as that copyright line and the licence's permission notice travel with them
(the tool writes them into every icons.css it makes); the full text is the `LICENSE` file of the
`lucide` package (https://github.com/lucide-icons/lucide).
